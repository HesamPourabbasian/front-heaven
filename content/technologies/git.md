## Why Git & GitHub Matter

Git and GitHub constitute the universal collaboration infrastructure of modern software engineering. From solo projects to global enterprise monorepos with thousands of contributors, version control safeguards code history, enables fearless experimentation in isolated branches, orchestrates automated CI/CD pipelines, and facilitates rigorous code review.

## Curriculum Overview

This master curriculum spans 3 difficulty tiers across 37 comprehensive lessons:
1. **Level 1 — Beginner (Lessons 1–10)**: Git Fundamentals, Repository Architecture (`.git`, `.gitignore`), Daily Development Cycle (`status`, `add`, `commit`, `diff`, `restore`), Atomic & Conventional Commits, Branching & Switching, Remotes (`push`, `pull`, `fetch`), GitHub Profile & Repository Anatomy, Cryptographic SSH Authentication (Ed25519), Collaboration Basics (Forks, PRs, Issues), and 8 Beginner Portfolio Labs.
2. **Level 2 — Intermediate (Lessons 11–22)**: Branching Strategies (GitHub Flow, Trunk-Based, Git Flow), Fast-Forward & Three-Way Merges, Conflict Resolution, Interactive Rebasing (`git rebase -i`), Undoing Mistakes (`restore`, `reset`, `revert`, `reflog`), Stashing, Tags & Semantic Versioning, Advanced GitHub Governance (`CODEOWNERS`, Templates, Branch Protection), Code Review Standards, GitHub Projects & Kanban, GitHub Actions CI/CD Basics, Git Internals (Blobs, Trees, Packs), and 6 Intermediate Labs.
3. **Level 3 — Advanced (Lessons 23–37)**: Advanced Git Internals (Content-Addressable Storage, Delta Compression, `git gc`), History Rewriting (`git-filter-repo`, Autosquash), Advanced Branch Management (Multi-remotes, Fork Sync), Diagnostic Tools (`git bisect`, `git blame`, `git rerere`, `git bundle`), Git Worktrees, Git Hooks (Husky, `lint-staged`), Enterprise Git Strategy (Release Trains, SSH/GPG Commit Signing), Advanced GitHub Actions (Matrix, Reusable Workflows, OIDC), GitHub Security (Dependabot, CodeQL, Secret Scanning), Enterprise Administration (RBAC, SAML/SSO), GitHub CLI & API Automation, Open Source Engineering, Monorepos & Large Repositories (Git LFS, Sparse Checkout, Partial Clones), Git Performance Optimization (`fsmonitor`, Commit-Graphs), and 3 Senior Capstone Projects.
