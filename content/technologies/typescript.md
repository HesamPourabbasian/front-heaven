## What you will learn

TypeScript is JavaScript with static types — a layer that checks your code before it ever runs, catches whole categories of bugs, and makes large codebases safe to maintain. It is the default choice for most modern teams.

This stage will cover:

- What TypeScript adds to JavaScript
- Type annotations and inference
- Interfaces, unions and generics
- Functions, classes and object types
- Configuring `tsconfig.json`
- Working with DOM types and third-party libraries
- Migrating an existing JavaScript project
