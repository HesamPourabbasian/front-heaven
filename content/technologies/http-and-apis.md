## What you will learn

Every time your page loads data from a server, HTTP is doing the talking. Understanding it transforms you from a developer who "copies fetch examples" into one who understands how the web actually works.

This stage will cover:

- What HTTP is and how requests travel
- Methods: GET, POST, PUT, PATCH, DELETE
- Status codes and headers
- JSON: the language of APIs
- RESTful API design basics
- Fetch, authentication and CORS
- Debugging with the browser DevTools
