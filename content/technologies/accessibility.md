## What you will learn

Accessibility (a11y) means designing and building products that everyone can use — including people using screen readers, keyboards or assistive technology. It is both a legal requirement and a mark of engineering quality.

This stage will cover:

- How assistive technology reads the web
- Semantic HTML as the accessibility foundation
- ARIA: when to use it and when to avoid it
- Keyboard navigation and focus management
- Color contrast and visual accessibility
- Accessible forms, dialogs and dynamic content
- Testing with automated tools and screen readers
