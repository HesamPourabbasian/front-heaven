## Why CSS Matters

HTML gives a page its structure, but without CSS the entire web would look like an unstyled plain text document. CSS — Cascading Style Sheets — is the language that controls how HTML is *presented*: colors, fonts, spacing, responsive layout, fluid typography, and hardware-accelerated animations. It is what transforms a bare skeleton into the polished, premium interfaces you use every day.

CSS is also where much of the true craft of front-end development lives. Layout systems like Flexbox, CSS Grid, and Subgrid, design token architectures, container queries, and subtle motion are all CSS capabilities that separate beginner projects from senior engineering work.

## 3-Level Progressive Learning Path

This comprehensive 41-topic curriculum is divided into 3 progressive tiers:

### 🟢 Level 1 — Beginner CSS (Topics 1 to 12)
- **Fundamentals & Syntax**: How CSS works, cascading, inheritance, specificity rules
- **Selectors & Specificity**: Universal, element, class, ID, attribute, combinators, and sibling selectors
- **Visuals & Units**: Colors (HEX, RGB, HSL), backgrounds, absolute vs relative units (px, rem, em, vw, vh, ch)
- **Layout Foundations**: Typography scale, Google Fonts, Box Model (content-box vs border-box), Display modes, Positioning (relative, absolute, fixed, sticky), Borders, Shadows, and Dynamic Math (`calc()`, `min()`, `max()`, `clamp()`)
- **Responsive Foundations**: Mobile-first architecture, media queries, breakpoints, and starter practice projects (Profile Card, Pricing Tier)

### 🟡 Level 2 — Intermediate CSS (Topics 13 to 25)
- **Modern Layout Engines**: 1D Flexbox (axes, flex-grow/shrink/basis, gap) and 2D CSS Grid (`repeat()`, `minmax()`, `auto-fit`, `grid-template-areas`)
- **Advanced Selectors & States**: Structural pseudo-classes, interactive `:focus-visible`, and modern super-selectors (`:is()`, `:where()`, `:has()`)
- **Motion & Visuals**: Pseudo-elements (`::before`, `::after`), GPU transitions, 2D/3D transforms, and `@keyframes` animations
- **Forms & Modern Features**: Custom form controls, `object-fit`, `aspect-ratio`, mesh gradients, CSS variables (`var()`), native CSS nesting, and BEM architecture

### 🔴 Level 3 — Advanced CSS (Topics 26 to 41)
- **Advanced Architecture & Sizing**: CSS Subgrid, intrinsic sizing (`min-content`, `max-content`, `fit-content`), and Masonry layouts
- **Engine Mechanics**: The 2026 cascade algorithm, Cascade Layers (`@layer`), and type-checked animatable `@property` custom properties
- **Cutting-Edge Features**: CSS Container Queries (`@container`), scroll-driven animations (`animation-timeline: scroll()`), `view-timeline`, glassmorphism (`backdrop-filter`), and 3D scenes
- **Production Standards**: Variable fonts, WCAG accessibility, rendering pipeline performance (reflow vs repaint vs composite), DevTools debugging, Preprocessors (Sass/PostCSS), Tailwind CSS frameworks, and capstone production projects
