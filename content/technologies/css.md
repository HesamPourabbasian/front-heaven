## Why CSS matters

HTML gives a page its structure, but without CSS the entire web would look like a plain text document. CSS — Cascading Style Sheets — is the language that controls how HTML is *presented*: colors, fonts, spacing, layout, responsiveness and animation. It is what transforms a bare skeleton into the polished, premium interfaces you use every day.

CSS is also where much of the craft of front-end development lives. Layout systems like Flexbox and Grid, design tokens, responsive rules and subtle motion are all CSS skills that separate beginner projects from professional ones. And because the web is viewed on everything from phones to 4K monitors, the ability to build interfaces that adapt gracefully is one of the most valuable skills you can learn.

## What you will learn

- How CSS rules, selectors and specificity work
- The box model and how space is calculated
- Typography, colors and modern units
- Flexbox and CSS Grid — the two layout systems you will use daily
- Responsive design with media queries and modern techniques
- Custom properties, transitions and animations

By the end of this stage you will be able to style a complete, responsive, modern-looking web page entirely by hand — no frameworks required.
