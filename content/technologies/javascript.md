## Why JavaScript matters

HTML structures a page and CSS styles it — but JavaScript is what makes it *alive*. JavaScript is the programming language of the browser: it powers the buttons you click, the forms you submit, the menus that slide open, the data that loads without refreshing the page, and the interactive dashboards you use at work. Today it is also used to build entire applications, run servers, and even power native mobile apps.

This stage is where you make the transition from writing *markup* to thinking like a *programmer*. It follows a complete path from variables and values through operators, control flow, objects, prototypes, data structures, scope, browser APIs, errors, asynchronous execution, networking, modules, iterators, memory and DevTools. These fundamentals are exactly what every modern framework (React, Vue, Angular) is built on top of.

## What you will learn

- Level 1: JavaScript fundamentals, variables, data types and type casting
- Level 2: equality, operators and expressions
- Level 3: control flow, loops and functions
- Level 4: objects, prototypes, classes, `this` and function binding
- Level 5: arrays, typed arrays, Map, WeakMap, Set, WeakSet and JSON
- Level 6: lexical scope, closures, recursion, strict mode and `this`
- Level 7: DOM APIs, events and browser JavaScript
- Level 8: Error objects, throwing, catching and recovery
- Level 9: event loop, timers, callbacks, promises and `async/await`
- Level 10: XMLHttpRequest, Fetch and working with APIs
- Level 11: ES Modules, CommonJS, iterators and generators
- Level 12: memory management, garbage collection and Browser DevTools

By the end of this stage you will be able to build, debug and optimize real applications with pure JavaScript — and you will be fully prepared for the frameworks that come next on the roadmap.
