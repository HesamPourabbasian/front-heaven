## Why JavaScript matters

HTML structures a page and CSS styles it — but JavaScript is what makes it *alive*. JavaScript is the programming language of the browser: it powers the buttons you click, the forms you submit, the menus that slide open, the data that loads without refreshing the page, and the interactive dashboards you use at work. Today it is also used to build entire applications, run servers, and even power native mobile apps.

This stage is where you make the transition from writing *markup* to thinking like a *programmer*. You will learn the core of the language — variables, data types, functions, objects, arrays, control flow — and then the browser-specific parts: the DOM, events, and asynchronous programming with promises and `fetch`. These fundamentals are exactly what every modern framework (React, Vue, Angular) is built on top of.

## What you will learn

- The core language: variables, types, operators, conditionals, loops
- Functions, scope, arrays and objects
- Manipulating the DOM and handling events
- Errors, JSON and how data moves through your programs
- Asynchronous JavaScript: promises, `async/await` and the Fetch API
- Modern essentials: closures, modules and web storage

By the end of this stage you will be able to build real, interactive applications with pure JavaScript — and you will be fully prepared for the frameworks that come next on the roadmap.
