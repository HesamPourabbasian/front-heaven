## Why HTML Matters

HTML — HyperText Markup Language — is the foundation of the entire web. Every website, app, and document you have ever seen in a browser is built on HTML.

---

## 12-Level Learning Path

- **Level 1 — HTML Fundamentals**: Introduction, Document Structure & Boilerplate, Block vs Inline Elements
- **Level 2 — Text & Content**: Headings (h1-h6), Paragraphs, Text Formatting, Lists, Quotes & Code
- **Level 3 — Links & Navigation**: Anchor Links, Absolute & Relative URLs, Navigation, Security
- **Level 4 — Images & Media**: Images, Responsive Formats, Figures, Video & Audio, iframes
- **Level 5 — Tables**: Semantic Tables, Cell Spanning, Accessible Headers
- **Level 6 — Forms & User Input**: Form Structure, GET vs POST, HTML5 Inputs, Controls, Validation
- **Level 7 — Semantic HTML**: Semantic Meaning, Landmark Layouts, Generic Containers
- **Level 8 — Accessibility**: WCAG Principles, Accessible Forms & Media, ARIA
- **Level 9 — SEO**: Search Crawlers, Metadata, Open Graph, Structured Data
- **Level 10 — Best Practices**: Formatting, W3C Validation, Progressive Enhancement, Performance
- **Level 11 — Advanced HTML**: Templates, Web Components & Shadow DOM, Browser APIs
- **Level 12 — Real Projects**: CSS Integration, JavaScript Script Loading, DevTools Mastery
