## Why HTML Matters

HTML — HyperText Markup Language — is the foundation of the entire web. Every website, app, and document you have ever seen in a browser is built on HTML. It is not a programming language in the traditional sense: it does not calculate algorithms or execute business logic. Instead, it *describes* and *structures* the content of a page — the headings, paragraphs, images, links, forms, and buttons — using a semantic tag system that browsers understand.

As a front-end developer, you will write HTML every single day. Before a page can be styled with CSS or made interactive with JavaScript, its structure must exist as clean, accessible HTML. Getting comfortable with HTML first means everything you learn afterwards has a solid foundation to build on.

## 12-Level Learning Path

This comprehensive curriculum takes you from absolute beginner to advanced HTML5 engineer:

- **Level 1 — HTML Fundamentals**: Introduction, Document Structure & Boilerplate, Block vs Inline Elements, Void Tags, Global Attributes
- **Level 2 — Text & Content**: Headings (h1-h6), Paragraphs, Semantic Text Formatting, Lists (ul, ol, dl), Quotes & Code
- **Level 3 — Links & Navigation**: Anchor Links, Absolute & Relative URLs, Fragment In-Page Navigation, Target & Rel Security
- **Level 4 — Images & Media**: Images, Responsive Formats, Figures & Captions, Native Video & Audio, Embedded iframes
- **Level 5 — Tables**: Semantic Tables (thead, tbody, tfoot), Cell Spanning (colspan/rowspan), Accessible Header Scoping
- **Level 6 — Forms & User Input**: Form Structure, GET vs POST, HTML5 Inputs, Controls (select, textarea, fieldset), Validation & File Uploads
- **Level 7 — Semantic HTML**: Semantic Meaning vs Div Soup, Landmark Layouts (header, nav, main, article, section, aside, footer), Generic Containers
- **Level 8 — Accessibility (a11y)**: POUR Principles, Accessible Forms, Accessible Media & Captions, ARIA Roles & Attributes
- **Level 9 — SEO**: Search Engine Crawlers, Metadata (Open Graph, Twitter Cards), Canonical URLs, JSON-LD Structured Data
- **Level 10 — HTML Best Practices**: Code Conventions & Formatting, W3C Validation & DevTools, Progressive Enhancement, Core Web Vitals Performance
- **Level 11 — Advanced HTML**: `<template>` Cloning, Native Web Components & Shadow DOM, Advanced Browser Web APIs
- **Level 12 — HTML in Real Projects**: CSS Integration & BEM, JavaScript Script Loading (defer/async) & Data Attributes, Backend Server Form Handling, DevTools Elements Panel Mastery
