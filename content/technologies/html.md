## Why HTML matters

HTML — HyperText Markup Language — is the foundation of the entire web. Every website, app and document you have ever seen in a browser is built on HTML. It is not a programming language in the traditional sense: it does not make decisions, calculate values or react to events. Instead, it *describes* the content of a page — the headings, paragraphs, images, links, forms and buttons — using a system of tags that browsers understand.

As a front-end developer, you will write HTML every single day. Before a page can be styled with CSS or made interactive with JavaScript, its structure must exist as HTML. Getting comfortable with HTML first means everything you learn afterwards — styling, layout, accessibility, SEO — has a solid foundation to build on.

## What you will learn

This stage takes you from absolute zero to confident:

- What HTML is and how the web works
- How to write valid, well-structured documents
- Tags, elements and attributes
- Links, images, lists, tables and forms
- Semantic HTML and why it changes everything
- Accessibility and SEO best practices baked into your markup

By the end of this stage you will be able to build the complete structure of a real, well-organised web page — the first milestone on your journey to becoming a front-end developer.
