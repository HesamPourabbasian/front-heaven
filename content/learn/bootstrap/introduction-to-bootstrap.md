## What is Bootstrap?

**Bootstrap** is a popular front-end toolkit for quickly designing and customizing responsive mobile-first sites with an extensive 12-column flexbox grid system and pre-built components.

---

## The 12-Column Grid

```html
<div class="container">
  <div class="row g-4">
    <div class="col-12 col-md-6 col-lg-4">
      <div class="card p-3">Column 1</div>
    </div>
    <div class="col-12 col-md-6 col-lg-4">
      <div class="card p-3">Column 2</div>
    </div>
    <div class="col-12 col-md-12 col-lg-4">
      <div class="card p-3">Column 3</div>
    </div>
  </div>
</div>
```

---

## Summary & Key Takeaways

- Bootstrap's 12-column grid makes building standard responsive column layouts fast and reliable.
