## Level 2 Project Showcase

Congratulations on completing **Level 2 — Intermediate CSS**! You now possess the skills to build professional, production-grade responsive interfaces.

---

## Project 1: Responsive Analytics Dashboard

Build an analytics dashboard featuring:
- Responsive CSS Grid layout with sidebar, header, stat cards, and chart panels.
- CSS variables for dark and light theme switching.
- Smooth hover animations on interactive cards.

---

## Project 2: Animated SaaS Landing Page

Build a modern SaaS landing page featuring:
- Sticky responsive navbar with blur backdrop filter.
- Hero section with fluid typography (`clamp()`) and mesh gradient background.
- 3-column pricing table with featured plan highlight.
- Smooth CSS transitions and keyframe animations on feature pills.

---

## Summary & Key Takeaways

- Combine Flexbox for micro-alignments and CSS Grid for macro-layouts.
- Use BEM and custom properties for scalable code structure.
- Add delightful micro-interactions with transitions and transforms.

---

## Practice Challenge

Choose either the Analytics Dashboard or SaaS Landing Page and build the complete responsive interface from scratch!
