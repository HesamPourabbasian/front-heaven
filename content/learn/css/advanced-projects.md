## Recommended Capstone Projects

### 1. Complete Design System Component Library
Build a cohesive design system featuring:
- Button variants (primary, secondary, outline, ghost, danger).
- Form controls with floating labels and validation states.
- Modal dialogs with frosted glass backdrops.
- Toast notifications with progress timers.
- Light and Dark mode tokens.

### 2. Full-Featured SaaS Dashboard
Build a complex application UI with:
- Collapsible responsive sidebar.
- Metric stat cards with live trend indicators.
- CSS Grid data analytics tables.
- Smooth CSS page transitions.
